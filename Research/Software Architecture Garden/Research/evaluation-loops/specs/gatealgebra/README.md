# gatealgebra — checked artifacts for research project 05

Companion artifacts for `05 - Constraint-First Gates and the Authority Ladder.md`.

## Layout

```text
lean/GateAlgebra.lean   core-Lean-4 model of the phased gate; five theorem
                        families plus two decidable counterexamples
go/                     standalone Go module: nominal-typed pure gate,
                        authority-ladder types, goldens, property tests,
                        and two seeded mutants the suite must catch
```

## Verification commands and observed results (2026-08-14)

```bash
cd lean && lean GateAlgebra.lean          # exit 0, no output — all theorems check
                                          # (Lean 4.33.0, core only, no mathlib)

cd go && GOWORK=off go vet ./...          # clean
cd go && GOWORK=off go test ./... -count=1
# ok  github.com/go-go-golems/garden-research/evaluation-loops/gatealgebra
# 13 tests: 7 golden scenarios, 4 property/counterexample tests,
# 2 authority-ladder guards; both seeded mutants are caught
```

Golden files under `go/testdata/` are generated by
`go test -run TestGateDecisionGoldens -update` and then reviewed by hand;
the transcript format matches ragopt's `decisionSummary` goldens.

The compile-error witness in `go/forge_attempt.go` was verified by placing the
untagged function in an external package and observing
`cannot refer to unexported field approvedBy in struct literal of type
gatealgebra.Application` (go1.26.5).

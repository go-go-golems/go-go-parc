Access Control and Authentication Access control and authentication requirements vary based on the connection method: USB: Considered a secure channel; no authentication is required. Requests are sent to the device at 10.0.4.20/api. Wi-Fi (LAN): Disabled by default for security. It must be enabled via the local web interface (10.0.4.20), which requires setting a password.
